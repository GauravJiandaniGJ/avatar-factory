Avatar Factory
JSON in. 3D coach out.

An open-source, fully headless avatar generator: Blender + MPFB scripted end-to-end. Physique, face, outfit, skin tone — even the print on the t-shirt — it’s all one config file. Output: rigged, lip-sync-ready GLB, ~5 MB, yours to ship.

Get it on GitHub Quickstart

One tool, two configs, two coaches. Copy a JSON file, change the sliders, run make.sh — a new person.

Why it exists

Ready Player Me shut down in January 2026 and took thousands of apps' avatar pipelines with it. Avatar Factory is the un-shut-downable answer: everything runs on your machine from open parts — Blender, the MPFB human generator, CC0 asset packs, and the MIT rig files from the TalkingHead project. No API keys, no per-avatar fees, no vendor.

What a config controls

💪 Physique

"muscle": 1.0 is a bodybuilder. Macro sliders + per-muscle-group targets: V-taper, delts, arms, jawline.

🗣 Lip-sync ready

52 ARKit face shapes + Oculus visemes baked in — drops straight into TalkingHead / three.js and talks.

🎽 Wardrobe & brand

Outfits from CC0 packs; the texture pre-step tints skin and prints your logo on the shirt from JSON.

🦴 Mixamo rig

Standard humanoid skeleton — plays Mixamo animations, runtime bone-scaling friendly.

📦 Small files

WebP textures, 16-bit quantization, sparse morphs: ~5 MB per avatar with a 2048 face.

⚖️ Clean licensing

MIT tool, CC0 ingredients (+2 CC-BY packs needing one credit line). Generated avatars are yours, commercially.

Quickstart

git clone https://github.com/GauravJiandaniGJ/avatar-factory && cd avatar-factory
./setup.sh        # one-time: Blender + MPFB + asset packs (~600MB, macOS)
./make.sh all      # male.json + female.json → out/*.glb

# new character = new config
cp male.json trainer-2.json   # edit physique/skin/hair/outfit…
./make.sh trainer-2
